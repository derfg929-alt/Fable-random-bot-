# Fable Randomizer

Telegram-бот для проведения конкурсов с полноценным **Telegram Mini App**,
административной панелью и единой базой данных.

Проект — не демонстрация интерфейса, а работающая система: серверная логика,
проверка подписки через Telegram Bot API, взвешенный розыгрыш с журналом
проверяемости, реферальная система и уведомления. Всё работает с одной базой.

## Возможности

- **Регистрация** при первом `/start`; повторный запуск не создаёт дубль и не
  начисляет бонус повторно.
- **Реферальная система**: персональная ссылка
  `https://t.me/BOT?start=ref_ID`, приглашённые друзья, защита от самореферала
  и повторного начисления.
- **Конкурсы**: название, описание, приз, изображение, даты, число победителей,
  обязательные каналы, статусы (ожидает / активен / завершён / отменён).
- **Проверка подписки** через Telegram Bot API непосредственно перед участием;
  если Telegram недоступен — условие считается **не выполненным** (fail-closed).
- **Взвешенный розыгрыш** без дублей с журналом проверяемости (commit-reveal).
- **Уведомления** с типами, переключателями и защитой от повторов.
- **Профиль, история участия, список победителей**.
- **Административная панель** в боте и в Mini App: статистика, конкурсы, каналы,
  пользователи, розыгрыши, настройки, журнал событий.
- **Telegram Mini App**: адаптивный интерфейс на Telegram Web App API с серверной
  проверкой `initData`.

## Установка и запуск

Требуется **Python 3.11+**.

```bash
git clone <your-repo-url>
cd Fable-random-bot-
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # Windows: copy .env.example .env
```

Заполни `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `BOT_USERNAME` | username бота без `@` |
| `OWNER_IDS` | твой числовой Telegram ID (владелец) |
| `WEBAPP_URL` | публичный HTTPS-адрес Mini App |
| `DATABASE_URL` | по умолчанию SQLite |
| `TIMEZONE` | часовой пояс, напр. `Europe/Moscow` |

Запуск:

```bash
python main.py
```

Бот запускается через long polling, FastAPI слушает `PORT` (по умолчанию 8000).
База создаётся автоматически при первом запуске.

Проверка, что сервис жив: `curl http://localhost:8000/api/health`.

## Настройка Telegram-бота (BotFather)

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задай имя и username, получи **токен** — вставь его в `BOT_TOKEN`.
3. Вставь username бота в `BOT_USERNAME`.
4. Узнай свой числовой Telegram ID (например, через [@userinfobot](https://t.me/userinfobot))
   и укажи в `OWNER_IDS`.
5. Настрой Mini App: `/newapp` → выбери бота → укажи название, описание,
   картинку, **Web App URL** (`WEBAPP_URL`) и короткое имя.
6. Дополнительно можно задать кнопку меню: `/setmenubutton` → выбери бота →
   укажи URL Mini App.

## Добавление бота в каналы

1. Добавь бота в канал и выдай права **администратора**.
2. В боте выполни `/addchannel @channel` (или `/addchannel -1001234567890`).
3. Бот проверит свои права и сохранит канал.
4. Каналы можно привязывать к нескольким конкурсам как обязательные.

> Если бот не администратор канала, проверка подписки невозможна — система
> сообщит об этом и **не** засчитает условие выполненным.

## HTTPS и Mini App

Telegram открывает Mini App только по **HTTPS**. Варианты:

- **Reverse-proxy** (nginx/Caddy) с сертификатом Let's Encrypt перед приложением
  на порту 8000. Пример nginx:

  ```nginx
  server {
    listen 443 ssl;
    server_name your-domain.example;
    ssl_certificate     /etc/letsencrypt/live/your-domain.example/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/your-domain.example/privkey.pem;
    location / { proxy_pass http://127.0.0.1:8000; proxy_set_header Host $host; }
  }
  ```

- **Туннель** для разработки: `cloudflared tunnel --url http://localhost:8000`
  или `ngrok http 8000` — полученный `https://…` адрес укажи в `WEBAPP_URL`.

После этого открой Mini App из бота. Сервер проверит подпись `initData` —
доверять ID из клиентского JavaScript нельзя.

## Как это работает

### Реферальная система
У каждого пользователя своя ссылка `https://t.me/BOT?start=ref_<ID>`. Бонус
начисляется **один раз** за нового пользователя при его первом `/start`.
Запрещены самореферал, смена пригласившего и повторное начисление. Размер бонуса —
внутренняя настройка алгоритма и **не показывается** пользователям (в интерфейсе
только количество приглашённых).

### Алгоритм выбора победителей
1. Берётся список действительных участников (условия выполнены, нет блокировки).
2. Каждому назначается относительный вес `1 + бонус` (0.01% за приглашённого,
   максимум +10%).
3. Победители выбираются **без повторений** взвешенным алгоритмом
   Efraimidis–Spirakis по seed.
4. В журнал сохраняются: снимок участников, commitment (`sha256(seed)`), сам seed,
   список победителей и `integrity_hash` записи.

Commitment фиксируется **до** выбора, seed раскрывается **после** — это и делает
розыгрыш проверяемым (обычный hash результата доказательством не является).

### Проверка подписки
Перед участием бот запрашивает `getChatMember` по каждому обязательному каналу.
Если Telegram не отвечает — условие **не** считается выполненным, пользователь
получает понятное сообщение и кнопку повторной проверки.

## База данных

Таблицы: `users`, `channels`, `contests`, `contest_channels`, `entries`,
`referrals`, `draw_logs`, `winners`, `notifications`, `admins`, `settings`,
`audit_logs`.

Ключевые ограничения:
- `users.telegram_id` — UNIQUE (одна регистрация на Telegram ID);
- `entries (contest_id, user_id)` — UNIQUE (одно участие на конкурс);
- `referrals.referred_id` — UNIQUE (бонус только один раз);
- `notifications (user_id, dedup_key)` — UNIQUE (нет повторных уведомлений);
- `contest_channels (contest_id, channel_id)` — UNIQUE.

Удаление конкурса — **мягкое** (`archived`): история участия и результаты
розыгрышей сохраняются. Каналы тоже архивируются.

## Безопасность

- проверка Telegram ID администраторов (`OWNER_IDS` + таблица `admins`);
- серверная проверка подписи `initData` (HMAC-SHA256) и срока `auth_date`;
- защита административных API (только для админов/владельцев);
- проверка прав бота в каналах;
- защита от повторной регистрации, повторного бонуса и повторного участия;
- защита от повторного розыгрыша (история всех попыток сохраняется);
- журналирование важных действий администраторов;
- секреты только в `.env` (в репозиторий не попадает).

## Тесты

```bash
python -m pytest -q
```

Тесты покрывают: регистрацию и рефералы, конкурсы и подписку, защиту от дублей,
алгоритм розыгрыша и проверяемость, уведомления, права администратора,
Mini App API (включая подпись `initData`), работу бота и сохранность данных
после перезапуска.

## Переход на PostgreSQL

1. Установи `asyncpg` (`pip install asyncpg`).
2. Укажи в `.env`:
   ```
   DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/fable_randomizer
   ```
3. Перезапусти приложение — таблицы создадутся автоматически.

Модели не используют SQLite-специфичных типов, поэтому переход не требует
изменения кода.
