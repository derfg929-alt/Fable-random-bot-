- SQLAlchemy services (`bot.py`, `api.py`, `admin.py`, `contests.py`, `draw.py`,
  `services.py`, `notifications.py`, `referrals.py`, `tasks.py`) imported models

## Gotchas
- `$!` after `cd ... && python main.py &` is the subshell PID, not Python; kill the
  real `python main.py` PID when testing signals.
- SQLite `:memory:` needs `StaticPool` or each connection sees an empty DB.
- `session_scope` must use `expire_on_commit=False` because handlers read ORM objects
  after the session closes.
- With `handle_signals=False`, aiogram does NOT stop polling on its own; `run_bot` needs a watcher that calls `dispatcher.stop_polling()` after checking `_running_lock.locked()`.
