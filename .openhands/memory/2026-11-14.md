## Gotchas reconfirmed
- `api.py` admin routes that need the bot (`publish`, `finish`, `cancel`, `update`)
  call `_bot_client()` → `api_runtime.get_bot()`, which raises if no bot is started.
  Any test/smoke hitting those routes must call `api_runtime.set_bot(...)` first.
- `PATCH` needs a *partial* model; `ContestIn` requires `title` (min_length=1), so a
  separate `ContestPatchIn` with all-optional fields is required.
